# Code of Conduct

Fermata is a workshop for hobby projects, and the only rule that really matters is: **don't make the workshop a worse place to work in.**

## What that means

- **Be kind in reviews.** Critique code, not people. Assume the author was doing their best with the time and context they had.
- **Give credit.** If you extend someone else's project, add yourself as a `contributor` in `fermata.json` — don't overwrite or remove existing authors.
- **Respect status.** If a project is marked `archived` or `paused`, don't push changes to it without checking with the original author first.
- **No harassment, no discrimination.** Personal attacks, slurs, sexualized content, sustained disruption of discussions, or harassment of any kind are not welcome. Anywhere. Ever.
- **Keep it on-topic.** Issues and PRs are for the work. Take broader debates elsewhere.

## Scope

This applies anywhere Fermata's community shows up — issues, PRs, discussions, commit messages, code comments, and any chat or social space tied to the project.

## Enforcement

If something feels off, open a private message to the repo owner (currently [@ScottyVenable](https://github.com/ScottyVenable)) or email the address listed on their GitHub profile. Reports are handled in confidence.

Consequences scale with severity and pattern:

1. **Private warning** — a quiet "hey, this wasn't okay."
2. **Public correction** — a comment from a maintainer asking the behavior to stop.
3. **Temporary block** — limited interaction with the repo for a defined period.
4. **Permanent ban** — for sustained or severe violations.

Maintainers have final say. Decisions can be appealed by replying to the enforcement notice.
